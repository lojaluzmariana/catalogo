LUZ MARIANA — MODO DE MANUTENÇÃO

COMO PUBLICAR
Envie todos os arquivos deste pacote para a RAIZ do repositório/site,
no mesmo local do CNAME e das logomarcas. Não envie para admin/ nem
para calculadora/.

O arquivo index.html contém o catálogo mais recente com a verificação
de manutenção. O catálogo foi preservado; não apague esse arquivo.
O catalogo.css e o sw.js preservam o visual e a atualização mais recentes.
Os ícones e a logo-horizontal.png que já existem no site devem permanecer.

A MANUTENÇÃO JÁ ESTÁ ATIVA NESTE PACOTE
O arquivo manutencao.json vem assim:

{
  "ativa": true
}

Após publicar, quem entrar no endereço principal ou em um link de produto
do catálogo será direcionado para manutencao.html. O botão de WhatsApp
permite continuar o atendimento. A página se adapta ao celular e computador.

COMO DESATIVAR SEM APAGAR
1. Abra manutencao.json no GitHub.
2. Troque true por false, sem aspas:

{
  "ativa": false
}

3. Salve a alteração e aguarde a publicação do GitHub Pages.
4. Abra o site novamente. O catálogo volta a aparecer.
   Se estiver na página de manutenção, use “Tentar acessar o catálogo
   novamente” ou recarregue a página.

COMO REATIVAR
Troque false por true e publique novamente.

OUTRA FORMA DE DESATIVAR
Você também pode excluir manutencao.html ou manutencao.json do repositório.
A verificação reconhece que o arquivo não existe e abre o catálogo.
NÃO exclua index.html: ele é a página principal do catálogo.
Para reativar após excluir arquivos, envie novamente os arquivos de manutenção.

ONDE O MODO SE APLICA
- Catálogo público da página inicial, incluindo links de produtos.
- A página de manutenção permanece até você desativar ou excluir o arquivo.
- admin/ e calculadora/ continuam acessíveis normalmente.
- Nenhum cadastro, pedido, cálculo ou estoque é alterado.
- Não é preciso alterar o Supabase ou executar SQL.
- A configuração é consultada sem cache em cada novo acesso.

VALIDAÇÃO
Conferido em navegador com dados simulados: manutenção ativa, desativação,
página excluída, configuração excluída, configuração inválida, link de produto,
botão de retorno e disposição em telas de 320, 390, 768 e 1366 px.
Nenhum pedido foi criado no banco real.
